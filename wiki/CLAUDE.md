# Схема базы знаний

Obsidian-friendly вики проекта TEOS-report. Язык контента — русский, имена файлов — английский kebab-case.

## Структура

```
wiki/
├── CLAUDE.md           # этот файл — схема и правила
├── index.md            # каталог всех страниц
├── log.md              # хронология операций
├── raw/assets/         # картинки, скриншоты, диаграммы
└── pages/
    ├── entities/       # модели, сервисы, компоненты, страницы
    ├── concepts/       # архитектура, потоки, соглашения
    ├── sources/        # саммари внешних источников (постановки, инциденты)
    └── analyses/       # ответы на вопросы, сравнения, решения
```

## Frontmatter

```yaml
---
title: Название страницы
type: entity | concept | source | analysis
tags: [тег1, тег2]
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: [пути к файлам проекта или внешние URL]
---
```

`updated:` поднимать при каждом редактировании. Даты только абсолютные, ISO.

## Obsidian-конвенции

- Связи — через `[[wikilinks]]` по имени файла без расширения: `[[support-chat-tree]]`.
- Алиас: `[[support-chat-tree|дерево вопросов]]`.
- Картинки: `![[diagram.png]]` из `raw/assets/`.
- Теги в frontmatter попадают в Tag Pane.
- У каждой страницы должна быть минимум одна входящая ссылка — хотя бы из `index.md`.
- Намеренно битый wikilink — это пометка «страницу ещё предстоит написать».

## Что НЕ писать

Git-историю, точные строки кода, текущие задачи, секреты. Код устаревает — описывать
концепции и ссылаться на файлы без номеров строк.

## Операции

- **Query** — сначала читать `index.md`, потом нужные страницы. Ценный ответ сохранять в `analyses/`.
- **Update** — при изменении архитектуры, моделей или интеграций обновить страницы, поднять `updated:`, добавить запись в `log.md`.
- **Ingest** — новый источник в `raw/` → саммари в `sources/` → обновить связанные страницы.
- **Lint** — искать противоречия, устаревшие утверждения, сироты и битые ссылки.
