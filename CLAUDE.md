# TEOS-report

Next.js (App Router) стенд: дашборды по сменам и финансам плюс интерактивные прототипы
техподдержки для согласования с командой и бэкендом.

## Wiki (База знаний)

В проекте есть LLM-поддерживаемая база знаний в `wiki/`.

**При любых вопросах о проекте:**
1. Сначала прочитай `wiki/index.md` — найди релевантные страницы.
2. Прочитай нужные страницы из `wiki/pages/`.
3. Отвечай, опираясь на вики. Если информации нет — ищи в коде и обновляй вики.

**При изменениях в проекте:**
- Если изменение затрагивает архитектуру, модели данных, интеграции или важные концепции —
  обнови соответствующие страницы в `wiki/pages/`.
- Обнови `wiki/index.md`, если создана новая страница.
- Добавь запись в `wiki/log.md` (дата, тип операции, затронутые страницы).

**Схема вики:** `wiki/CLAUDE.md`

## Команды

```bash
npm run dev     # дев-сервер
npm run build   # сборка
npm run lint    # eslint
```

Тестового фреймворка в проекте нет: проверка — сборка, линт и ручной проход по страницам.

## Соглашения

- Строгая типизация, `any` не используется.
- Эмодзи в интерфейсе не используются — только SVG-иконки из `lucide-react`.
- Мок-данные детерминированные: без `Math.random()` и `new Date()` в рендере.
