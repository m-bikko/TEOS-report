# Иконки

SVG-файлы иконок, которые использует интерфейс техподдержки. Выгружены из пакета
`lucide-react` версии, указанной в `package.json`, поэтому один в один совпадают с тем,
что рисуется на страницах стенда.

## Где лежат

```
public/icons/
├── nodes/    иконки узлов дерева частых вопросов (10 файлов)
├── chat/     иконки внутри чата (14 файлов)
├── LICENSE.txt
└── README.md
```

Папка `public/` раздаётся Next.js как статика, поэтому в браузере и в мобильном
приложении файлы доступны по адресу без префикса `public`:

| На диске | По сети |
|---|---|
| `public/icons/nodes/wallet.svg` | `/icons/nodes/wallet.svg` |
| `public/icons/chat/bot.svg` | `/icons/chat/bot.svg` |

## nodes — иконки узлов дерева

Это те иконки, которые выбираются в конструкторе чата и **хранятся в базе**:
колонка `icon` таблицы `support_chat_node` содержит имя в PascalCase.

Правило перевода имени в файл: PascalCase → kebab-case.

| Значение `icon` в БД | Файл |
|---|---|
| `CalendarClock` | `nodes/calendar-clock.svg` |
| `Clock` | `nodes/clock.svg` |
| `CreditCard` | `nodes/credit-card.svg` |
| `FileText` | `nodes/file-text.svg` |
| `HelpCircle` | `nodes/help-circle.svg` |
| `MapPin` | `nodes/map-pin.svg` |
| `ShieldCheck` | `nodes/shield-check.svg` |
| `Truck` | `nodes/truck.svg` |
| `UserCog` | `nodes/user-cog.svg` |
| `Wallet` | `nodes/wallet.svg` |

Список допустимых значений задан в `src/app/_support-shared/icons.tsx`. Если туда
добавляют иконку, файл нужно выгрузить сюда же — иначе клиенты, которые берут
картинку по имени из БД, получат пустоту.

`HelpCircle` работает и как запасной вариант: он подставляется, когда `icon` пустой
или содержит незнакомое имя.

## chat — иконки чата

Нужны мобильной команде, чтобы повторить вёрстку переписки: пометка автоответа,
пометка оператора, кнопки действий под ответом, вложения, поле ввода.

## Как красить

Иконки нарисованы обводкой, без заливки: `fill="none"`, `stroke="currentColor"`,
толщина 2 при размере 24×24. Цвет наследуется от текста, поэтому в вебе достаточно
вставить SVG инлайном и задать `color`. Через `<img>` цвет не наследуется — там нужен
файл нужного цвета или CSS-маска.

Размер меняется атрибутами `width`/`height`: `viewBox` остаётся `0 0 24 24`.

## Лицензия

Lucide, ISC — см. `LICENSE.txt`. Лицензия разрешает коммерческое использование,
требование одно: сохранять текст лицензии. Логотип TEOS сюда не входит, он поставляется
отдельным файлом `Logo.svg` по правилам брендбука.

## Как обновить

Файлы не правятся руками. После смены версии `lucide-react` или пополнения списка
в `icons.tsx` выгрузку нужно повторить тем же способом: прочитать `__iconNode` из
`node_modules/lucide-react/dist/esm/icons/<kebab>.js` и обернуть в стандартный SVG.
Часть имён — алиасы, их файл только реэкспортирует другой, цепочку надо разворачивать.
